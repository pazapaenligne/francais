📰 Le Reporter — Temps composés

Passé composé, plus-que-parfait, futur antérieur, passé antérieur
Référentiel
Correspondances
Passé composé = auxiliaire au PRÉSENT + participe passé.
Plus-que-parfait = auxiliaire à l'IMPARFAIT + participe passé.
Passé antérieur = auxiliaire au PASSÉ SIMPLE + participe passé.
Futur antérieur = auxiliaire au FUTUR SIMPLE + participe passé.
Choix de l'auxiliaire
— ÊTRE : verbes de mouvement et de changement d'état (aller, venir, partir, arriver, naître, mourir, entrer, sortir, monter, descendre, rester, tomber, passer…) + verbes pronominaux.
— AVOIR : tous les autres verbes.
Participes passés irréguliers courants
avoir → eu ; être → été ; faire → fait ; prendre → pris ; venir → venu ; voir → vu ; dire → dit ; mettre → mis ; écrire → écrit ; lire → lu.
