ces = déterminant démonstratif pluriel. Test : remplacer par les ou des. Ex. : ces récits → les récits.
ses = déterminant possessif pluriel (3e pers.). Test : remplacer par mes ou tes. Ex. : ses Fables → mes Fables.
s'est = pronom réfléchi + auxiliaire être. Test imparfait : remplacer par s'était. Ex. : s'est laissé → s'était laissé.
c'est = pronom démonstratif + auxiliaire être. Test : remplacer par cela est. Ex. : c'est un recueil → cela est un recueil.
