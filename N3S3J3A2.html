📚 Référentiel — ces / ses / c'est / s'est
ces
Déterminant démonstratif pluriel. Remplaçable par les.
Ex. : Ces pages → Les pages ✓
ses
Déterminant possessif pluriel (3e pers. sing.). Remplaçable par mes.
Ex. : Ses œuvres → Mes œuvres ✓
c'est
Ce + est. Remplaçable par cela est ou c'était.
Ex. : C'est un auteur → Cela est un auteur ✓
s'est
Verbe pronominal au passé composé. Remplaçable par s'était.
Ex. : Il s'est révélé → Il s'était révélé ✓
