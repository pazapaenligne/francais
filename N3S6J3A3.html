Leur / Leurs
Leur / Leurs — déterminant (adjectif possessif)

Placé devant un NOM. S'accorde en nombre avec le nom qu'il accompagne.

Singulier si le nom est singulier : leur maison (une maison).

Pluriel si le nom est pluriel : leurs maisons (des maisons).

✂️ Test : remplacer par « son / ses ». Si « son » fonctionne → leur. Si « ses » fonctionne → leurs.

Ex. : « Ils rangent leur chambre. » → leur chambre (une chambre par personne → sing.) → son fonctionne ✓ → leur.

Ex. : « Ils rangent leurs affaires. » → leurs affaires (plusieurs affaires → plur.) → ses fonctionne ✓ → leurs.

Leur — pronom personnel (complément)

Remplace un groupe de personnes (3e pers. plur.) COI. TOUJOURS INVARIABLE : jamais de -s.

Placé avant un VERBE.

✂️ Test : remplacer par « lui » (sing.) : si la phrase reste logique, c'est le pronom → leur invariable.

Ex. : « Je leur parle. » → Je lui parle. ✓ → leur = pronom invariable.

Astuce globale :
— Leur est suivi d'un NOM → déterminant → s'accorde.
— Leur est suivi d'un VERBE → pronom → invariable.
— Test déterminant : son/ses.
— Test pronom : lui.
