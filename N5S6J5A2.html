LE PARTICIPE PASSÉ EMPLOYÉ AVEC ÊTRE

Le participe passé s'accorde en GENRE (masculin/féminin) et en NOMBRE (singulier/pluriel) avec le SUJET du verbe.

Méthode

  1. Trouver le sujet.
  2. Vérifier son genre et son nombre.
  3. Accorder le participe passé en conséquence.

Terminaisons

Masc. sing. : -é, -i, -u, -t… Ex. : il est parti.
Fém. sing. : -ée, -ie, -ue, -te… Ex. : elle est partie.
Masc. plur. : -és, -is, -us, -ts… Ex. : ils sont partis.
Fém. plur. : -ées, -ies, -ues, -tes… Ex. : elles sont parties.

Verbes qui se conjuguent avec être

  • Verbes de mouvement : aller, venir, partir, arriver, entrer, sortir, monter, descendre, naître, mourir, tomber, rester, passer…
  • Tous les verbes pronominaux : se lever, se souvenir…

LE SUBJONCTIF PRÉSENT

Employé après : vouloir que, souhaiter que, il faut que, il est nécessaire que, douter que, craindre que, avoir peur que…

Formation

3e pers. plur. présent indicatif → supprimer -ent → + terminaisons : -e, -es, -e, -ions, -iez, -ent.

Irréguliers

être → sois / soit / soyons / soyez / soient.
avoir → aie / aies / ait / ayons / ayez / aient.
aller → aille / ailles / aille / allions / alliez / aillent.
faire → fasse / fasses / fasse / fassions / fassiez / fassent.
