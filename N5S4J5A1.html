📖 Référentiel
CONDITIONNEL PRÉSENT
Radical du futur simple + terminaisons de l’imparfait (-ais, -ais, -ait, -ions, -iez, -aient).
Ex. : finir → je finirais.
Irréguliers : être → serais ; avoir → aurais ; aller → irais ; faire → ferais ; pouvoir → pourrais.
ACCORD SUJET-VERBE
Règle générale : le verbe s’accorde en personne et en nombre avec son sujet.

Sujet inversé : accord avec le sujet placé après le verbe.
Sujets multiples (et) : verbe au pluriel.
Sujet éloigné : repérer le noyau du sujet.
Nom collectif + complément : accord avec le complément.
