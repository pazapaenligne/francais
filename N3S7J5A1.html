Question 1 — Accord sujet-verbe
4 points — clique sur la forme correcte
0/4
Clique sur la forme verbale correcte pour chaque phrase.
Corrigé
1. arrivaient — Sujet inversé : les pompiers (pluriel) est après le verbe.
2. courait — Noyau du sujet : bande (singulier), pas « enfants ».
3. comprenaient — Ni… ni : deux sujets → pluriel.
4. connais — Qui reprend toi → 2e personne du singulier.
📝
Question 2 — Identifier le temps
4 points — clique sur le temps du verbe souligné
0/4
Clique sur le temps du verbe souligné.
Corrigé
1. soufflait → imparfait — action qui dure (décor).
2. s’ouvrit → passé simple — action ponctuelle, premier plan.
3. avaient entendu → plus-que-parfait — action antérieure.
4. grondait → imparfait — décor, description continue.
📈
Question 3 — Relier temps et valeurs
3 points — clique sur un temps, puis sur sa valeur
0/3
Clique sur un temps (colonne gauche), puis sur sa valeur (colonne droite).
Temps
Valeur dans le récit
Corrigé
Imparfait → décor, habitude, description.
Passé simple → action de premier plan, brève.
Plus-que-parfait → action antérieure à une autre action passée.
📚 À retenir
Le verbe s’accorde avec son sujet réel, même inversé ou éloigné. Dans le récit : l’imparfait décrit, le passé simple fait avancer l’action, le plus-que-parfait marque l’antériorité.
