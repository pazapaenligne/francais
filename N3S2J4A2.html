📚 Référentiel — Impératif présent et passé
Impératif présent
3 personnes (2e sing. / 1re plur. / 2e plur.). Pas de pronom sujet. 1er groupe, 2e sing. : pas de -s (sauf devant y / en). Irréguliers : sois / soyons / soyez · aie / ayons / ayez · sache / sachons / sachez · va / allons / allez.
Impératif passé
Formation : impératif présent de l'auxiliaire + participe passé. Avec avoir : aie lu / ayons fini / ayez terminé. Avec être : sois parti(e) / soyons arrivés / soyez rentrés. Valeur : action accomplie AVANT un moment ou une action ultérieure.
