📖 Référentiel — Accord de l’adjectif
L’adjectif s’accorde en genre et en nombre avec le nom ou le pronom qu’il qualifie.
Épithète : placé directement à côté du nom. Attribut du sujet : séparé du nom par un verbe d’état ; s’accorde avec le sujet. Apposé : séparé du nom par une virgule.
Cas particuliers : -al → pluriel masc. en -aux (sauf banals, fatals, natals, navals). Irréguliers : vieux → vieille(s) ; beau → belle(s) ; nouveau → nouvelle(s) ; blanc → blanche(s). Couleur composée ou issue d’un nom : invariable. Adjectif employé comme adverbe : invariable.
