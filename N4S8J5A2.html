Je m'entraîne

🧪 Labo bilan — ces / ses / c'est / s'est & impératif
📋 Référentiel
CES
Déterminant démonstratif pluriel, devant un nom pluriel. Test : remplacer par « les »/« des ». « Ces documents sont importants. » → Les documents ✓
SES
Déterminant possessif pluriel (3e pers.), devant un nom pluriel. Test : remplacer par « mes »/« tes ». « Il range ses affaires. » → mes affaires ✓
C'EST
Pronom démonstratif ce + être au présent. Test : remplacer par « cela est ». « C'est une bonne idée. » → Cela est ✓
S'EST
Pronom réfléchi se + être, toujours suivi d'un participe passé. Test : remplacer par « s'était ». « Elle s'est levée tôt. » → s'était levée ✓
⚠ Astuce globale : devant un nom pluriel → ces ou ses (test mes/tes → ses ; test les/des → ces). Devant un participe passé → s'est. Seul ou devant un nom/adjectif → c'est (test cela est).
Rappel impératif présent — 3 personnes (tu, nous, vous), sans pronom : 1er groupe : tu -e, nous -ons, vous -ez · 2e groupe : tu -is, nous -issons, vous -issez · 3e groupe : mêmes formes que l'indicatif présent · Irréguliers : être → sois/soyons/soyez · avoir → aie/ayons/ayez · aller → va/allons/allez · savoir → sache/sachons/sachez.
