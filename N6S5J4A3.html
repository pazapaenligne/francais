2e groupe (-ir) : radical + -is, -is, -it, -îmes, -îtes, -irent. Ex. : grandir → il grandit, rougir → ils rougirent
Irréguliers : voir, avoir, prendre, venir, être, faire, courir, obéir → formes à mémoriser (radicaux imprévisibles)
Attention : sans accent dans la grille. Ex. : é → E, è → E, â → A.
