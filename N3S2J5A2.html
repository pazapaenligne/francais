Impératif présent
2e sing. / 1re plur. / 2e plur. Sans pronom sujet. 1er groupe, 2e sing. : pas de -s. Irréguliers : sois / soyons / soyez · aie / ayons / ayez · sache / sachons / sachez · veuille / veuillons / veuillez · va / allons / allez.
Impératif passé
Imp. présent de l'auxiliaire + p.p. Avec avoir : aie / ayons / ayez + p.p. Avec être : sois / soyons / soyez + p.p. (accordé). Valeur : action accomplie AVANT un moment ultérieur.
Accord de l'adjectif
S'accorde avec le nom noyau. Attribut : avec le sujet. En -al, masc. plur. → -aux. Irréguliers : doux / douce · faux / fausse · long / longue · neuf / neuve · loyal / loyaux.
