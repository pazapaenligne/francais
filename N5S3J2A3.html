TYPES (3) : Déclaratif : donne une information. Se termine par un point. Interrogatif : pose une question. Se termine par un point d'interrogation. Injonctif : exprime un ordre, un conseil, une interdiction. Verbe à l'impératif ou à l'infinitif. Se termine par un point ou un point d'exclamation. FORMES : Affirmative / Négative (ne… pas, ne… plus, ne… jamais, ne… rien…) Neutre / Exclamative (quel, quelle, que, comme… + point d'exclamation) Active / Passive (être + participe passé ; sujet subit l'action) Personnelle / Impersonnelle (il impersonnel sans référent : il pleut, il faut, il est nécessaire…) RÈGLE FONDAMENTALE : Une phrase combine toujours un TYPE et une ou plusieurs FORMES. Ex. : « N'attendez plus ! » → Type : injonctif. → Formes : négative + exclamative.
