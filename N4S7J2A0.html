📖 Les types et les formes de phrases
1
Les types de phrases

Le type d’une phrase indique l’intention de celui qui parle ou écrit. Il existe trois types de phrases.

Type
À quoi sert-il ?
Exemple
Déclaratif
Donner une information, raconter, expliquer.
Le train arrive à huit heures.
Interrogatif
Poser une question.
Le train arrive-t-il à huit heures ?
Injonctif
Donner un ordre, un conseil, une consigne ou une interdiction.
Attendez le train.

💡 À retenir : le type de phrase dépend de l’intention de communication.

🔍 Vérifions ta lecture : complète le texte

Le type sert à donner une information.

Le type sert à poser une question.

Le type sert à donner un ordre ou une consigne.

2
Les formes de phrases

La forme d’une phrase apporte une précision sur sa construction ou sur l’effet recherché. Une phrase peut être :

Forme
Caractéristique
Exemple
Affirmative
Elle affirme quelque chose.
Le train est à l’heure.
Négative
Elle contient une négation.
Le train n’est pas à l’heure.
Exclamative
Elle exprime une émotion ou une forte réaction.
Comme cette œuvre est magnifique !
Passive
Le sujet subit l’action.
La gare est fermée par les agents.

💡 Une même phrase possède un type et une ou plusieurs formes.

Exemple : Ne pars pas !

Type : injonctif. Forme : négative et exclamative.

🔍 Vérifions ta lecture : complète le texte

La forme affirme quelque chose.

La forme contient une négation.

La forme exprime une émotion.

Dans la forme , le sujet subit l’action.
