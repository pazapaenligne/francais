Terminaisons du passé simple
1er groupe
-ai, -as, -a, -âmes, -âtes, -èrent.
2e groupe et certains verbes du 3e groupe
-is, -is, -it, -îmes, -îtes, -irent.
Verbes irréguliers en -us
-us, -us, -ut, -ûmes, -ûtes, -urent (pouvoir → put, vouloir → voulut, savoir → sut, croire → crut).
Verbes irréguliers en -ins
-ins, -ins, -int, -înmes, -întes, -inrent (venir → vint, tenir → tint).
Radicaux à mémoriser
Être → fus ; avoir → eus ; faire → fis ; voir → vis ; dire → dis ; prendre → pris.
Quel / Quelle / Qu'elle
QUEL / QUELS
Déterminant ou pronom exclamatif/interrogatif, masculin. Test : remplacer par quel grand / quels grands.
QUELLE / QUELLES
Déterminant ou pronom exclamatif/interrogatif, féminin. Test : remplacer par quelle grande / quelles grandes.
QU'ELLE / QU'ELLES
Conjonction que + pronom sujet elle/elles, toujours suivi d'un verbe conjugué. Test : remplacer elle/elles par il/ils — si la phrase reste correcte → qu'elle(s).
